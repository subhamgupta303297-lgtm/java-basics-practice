
## 🧩 Pattern Problems (Nested Loops)

Solutions for foundational 2D pattern-printing problems implemented using nested `for` loops, space-to-character ratio logic, and 2D coordinate parity checks (Apna College — Lecture 5).

### 📋 Problems Included

1. **Solid Rectangle** — Standard 2D grid iteration ($n \times m$).
2. **Hollow Rectangle** — Boundary condition checks ($i=1, i=n, j=1, j=m$).
3. **Half Pyramid** — Dynamic column iteration bounded by the current row index ($j \le i$).
4. **Inverted Half Pyramid** — Reverse row traversal decrementing from $n$ to $1$.
5. **180° Rotated Inverted Half Pyramid** — Multi-loop handling for dynamic spaces $(n-i)$ and asterisks ($i$).
6. **Half Pyramid with Numbers** — Numeric column index streaming.
7. **Inverted Half Pyramid with Numbers** — Decreasing numeric range generation per row.
8. **Floyd's Triangle** — Continuous global counter incrementation across rows.
9. **0-1 Triangle** — Coordinate parity logic based on the sum of row and column indices (`(i + j) % 2 == 0`).
